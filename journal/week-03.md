### CT 01 · Understanding Data

_2026-08-19 · logged 2026-08-19 18:55 UTC_

- **Clinic topic:** CT 01 · Understanding Data
- **What was taught:** A breakdown which helps to get a clear picture of what a data is about.
- **What you now understand:** Every dataset can be understood through three independent lenses — and all three apply at the same time.
FORMAT — How the data is saved
This is the file container or encoding.
Examples: CSV, Excel, JSON, Parquet, XML, images.
The same data can appear in many formats.
TYPE — What kind of value it is
This describes the nature of each field.
Examples: number, text, date, boolean, currency.
Type determines what operations are valid (e.g., you can sum numbers but not text). 
STRUCTURE — How the data is organised
This is the shape of the data and how records relate.
Examples: structured (tables), semi‑structured (JSON/XML), unstructured (images/text).
It tells you whether data is flat, nested, or free‑form.
